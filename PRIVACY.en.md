# LexiLoom 0.4.0 privacy notice

[中文](PRIVACY.md)

The extension reads the text you select so it can tell an English word from a Chinese word and place a card beside it. It does not scan or upload the page, keep a browsing or lookup history, or create an account.

- **English words in the English interface:** By default only that word goes to `https://api.dictionaryapi.dev` (Free Dictionary). The card shows the English definition, pronunciation and examples. Choosing the demo, Oxford or Cambridge queries that source instead. An English word's card still leaves out Chinese definitions. This choice is stored on its own and does not change the English-word source used by the Chinese interface.
- **Chinese words:** In either interface, the selected word and corresponding spellings needed for script lookup go to `https://api.wiktapi.dev`, for Chinese entries in Chinese and English Wiktionary. An ambiguous character may query both its original and converted spelling; the card explains the scope. When the selected region is Taiwan, the word also goes to `https://www.moedict.tw` for the Ministry of Education dictionary. Hong Kong and mainland lookups do not call Moedict. The English interface still shows the Chinese spelling and reading.
- **English words in the Chinese interface:** The word goes to `https://api.wiktapi.dev` first. If that source has no entry or the request fails, the same word goes to Free Dictionary, and the card says why. The extension does not open a hidden tab, submit a search history, or run scripts from the dictionary site.
- **Free Dictionary:** Only the looked-up word is sent to `https://api.dictionaryapi.dev`. Pronunciation buttons in online modes may request the HTTPS audio URL the API already provides, for example on Wikimedia Commons. Dictionary and audio hosts handle the request and network metadata under their own policies.
- **Local demo:** English demo entries make no network request. The Chinese practice section uses the online sources described above. System speech is provided by the browser or operating system, and how the voice is processed depends on that voice.
- **Oxford / Cambridge:** The selected word is sent to the fixed local address `http://127.0.0.1:47821`. The local service then queries the official API you chose. Official keys live in your own `bridge/.env` and are not inside the extension package. The local service does not log query words or API keys and does not persistently cache official entries.
- **Local storage:** The extension stores whether it is enabled, the English-word source for the Chinese interface, the English-word source for the English interface, the Chinese region (automatic, mainland, Hong Kong or Taiwan), the built-in guidance sites you disabled, your custom link templates, and the local service token. It does not use Chrome sync. Only the background and trusted extension pages can read that storage. Extension storage is not disk encryption. Uninstalling the extension removes these settings. `bridge/.env` is a separate file you keep or delete yourself.
- **Source links and the guidance directory:** A dictionary site opens only when you click, with `noopener noreferrer`. The link directory only builds external links to dictionary sites; the extension does not fetch or rehost the body of those pages, and once you open a link the destination site's own privacy policy applies.

Content-script access to ordinary HTTP and HTTPS pages is required so a double-click or a selection can be answered. Lookups need host permission for `api.wiktapi.dev`, `api.dictionaryapi.dev`, `www.moedict.tw`, and the local address. The guidance directory adds no host permission for the sites it links to. At most four network lookups run at once. Entries are not cached persistently. Chrome host patterns cannot be limited by port, so the manifest permission covers `127.0.0.1` while the code pins the service to port 47821. The extension does not request clipboard, history, cookie, microphone, or camera permissions. Inputs, password fields, and editable regions do not trigger lookup.

Cards render text only. Cambridge entry HTML is reduced to text in the local service before it reaches the page, and it is not executed as page HTML. There is no analytics, ad tracking, or telemetry.
