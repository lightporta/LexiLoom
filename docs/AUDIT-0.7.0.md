# 0.7.0 验收与出词效率审计

日期：2026-11-03。基线为用户已合并的 `main@9fb1748`（0.6.1），开始时工作区干净。本轮保留现有选词、多卡、导向和五语到简体中文的范围。

## 发现与修复

| 问题 | 影响与处理 | 证据 |
| --- | --- | --- |
| 同词反复选中、多个页面同时查词都会重新取完整响应 | 共享有界内存成功结果，并合并进行中请求；实际词源/语言/地区/界面隔离；官方 bridge 排除 | 7 项新增契约测试；真实 Chromium 效率检查及 0.6.1 对比 |
| 已过期排队请求不能立即退出 | AbortSignal 触发时从队列移除，返回取消错误；不占后续请求槽 | 受控未结束请求 + 排队取消/后续请求/Request signal 覆盖检查 |
| 首次选词先等语言包，再读取设置 | 两个独立等待并行启动，减少冷启动串行步骤 | 浏览器门闩测试：语言包未放行时必须已发 GET_SETTINGS；旧代码失败、新代码通过 |
| 词卡出现前按 Escape 无效，慢回复会晚弹出 | 跟踪待完成选词，Escape 使 session 失效并取消 launcher 定时器 | 新增取消、恢复、定时器取消 3 项浏览器回归 |
| 法语/西语句首大写缺词 | 原词被确认 404 后才查小写；保留选中词和实际词头出处；德语保留大小写 | 原生 API `Bonjour → bonjour` / `Niño → niño`；4 项浏览器回归 |
| 英/中文 404 对词头身份验证较宽 | 三类 WiktApi 路径共用严格缺词校验，不把别的词或路由的 404 当无词 | 词头/版本/语言 URL 冲突的单测 |
| 英/中文坏 JSON / 超大内容误报网络 | 成功响应格式异常归 `unsupported-format` | 两种格式失败及正文/头部大小限制单测 |
| 中文部分语料临时失败仍返回可用词卡 | 原始适配器标记不可缓存，避免下次查询被部分结果拦住 | 中文部分结果断言 + engine 重试契约；标记不传给页面 |

旧浏览器 QA 在同一个词上更换响应夹具，加入真实缓存后会正确命中旧成功结果，导致故障/延迟断言没有走到目标分支。相关场景改为独立冷词，保留产品缓存，不添加测试专用清空接口，也不降低原断言。

## 性能数据

详见 [完整对比](performance-validation-0.7.0.json)。同一台 macOS、Node 24.16.0、Chromium 156.0.8078.4，分别加载基线 0.6.1 与 0.7.0 的真实 MV3 扩展；受控英文 UI，Free Dictionary 响应替换为自编数据并固定等待 150ms。计时还包含浏览器调度与消息传递，因此实际数值不等于注入的 150ms。

| 场景 | 0.6.1 | 0.7.0 |
| --- | --- | --- |
| 同词连续查 6 次的外部请求数 | 6 | 1 |
| 后 5 次消息往返中位数 | 245.8ms | 0.6ms |
| 同词 8 次并发的请求数 | 8 | 1 |
| 8 次并发全部完成 | 487.9ms | 253.4ms |
| 第二次双击至可见完成词卡（单次） | 303.1ms | 28.7ms |
| 首次未缓存词的消息往返（单次） | 238.5ms | 258.2ms |

结论只限于重复查询和相同请求排队的消除。**没有证据表明新词公网首查更快**；首查样本甚至略慢，不能用热缓存数据宣称整体“秒出词”。后台停止会清除内存缓存。CI 只验请求次数、结果与恢复能力，计时不设硬阈值。

## 工作栈

- 保留原生 JavaScript + Manifest V3，安装使用不需要 Node；没有新增产品运行依赖。
- Node 24 LTS 作为开发与三平台浏览器 CI 主力；保留 Node 22 最低支持的独立兼容任务。Node 官网确认这两个主版本均仍为 LTS；采用已有本机验证环境 24，而非刚进入 LTS 的 26。[Node 发布周期](https://nodejs.org/en/about/previous-releases)
- npm 查询确认 Playwright 1.64.1、内置 OpenCC 1.4.2 已为最新版本，保持锁定；`npm audit` 当前 0 项已知漏洞。
- Chrome service worker 不能动态 `import()`，因此保留静态导入；不把普通网页的懒加载方式直接用于 MV3。[Chrome 文档](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/basics)

## 仍存在的边界

- 首查受第三方网络与语料覆盖影响，中文组合词条仍等待本次各语料返回；没有新增持久离线词库或分阶段流式出词。
- 日/韩读音、例句及各语言义项覆盖由词源决定；尚无通用变形词还原，法/西小写回退不是词形分析。
- 仍为单词词卡；PDF、iframe、编辑器、Chrome 内部页与句子翻译未扩展。
- Oxford/Cambridge 仍需真实授权凭据联调；本轮没有用模拟数据代替该联通证明。
- 本机实际为 macOS，界面语言由受控 API 输入；新版 Linux/Windows 以及 Node 24 三平台 CI 需用户推送后确认。

完整检查、真实词源样本、安装包与发布状态见 [验收记录](VALIDATION.md)。
