# 0.5.0 审查与处理

日期：2026-11-02。基线为用户的 `dc7df92`，原有 0.4.0 功能保留。范围包括词卡查词、导向路由、自定义模板、设置并发、导航 UI、测试和打包。仓库外的路线图将“导向”定义为词典站目录与网址路由，本轮沿用该定义。

## 已修复的缺陷

| 问题 | 实际影响 | 修复与证据 |
| --- | --- | --- |
| `GET_SETTINGS` 缺少 `englishProvider`，广播却包含它 | 预存演示词源后新开英文网页，第一次切成 Free Dictionary 不触发重查，仍显示演示词条 | 初次读取与广播统一公开结构；真实浏览器从这个初始状态验证原卡片保持展开并显示新来源 |
| 设置页保存所有字段，而不是用户改过的字段 | 旧窗口只改地区，也会覆盖另一窗口刚保存的暂停状态和自定义模板 | 相对加载基线只提交改动字段；浏览器回归验证暂停与模板都保留 |
| 读取设置失败后仍可提交 | 初始空表单可能覆盖已存设置 | 读取成功前禁用控件，失败保持禁用；模拟读取拒绝后，程序提交也没有发出 SAVE 请求 |
| `{word}` 可放进 URL 主机部分 | 选中的词会改变外链实际目标站点 | 模板禁止 authority 占位符，填入后再次校验 origin；路径、查询和片段仍支持编码替换 |
| 长名称、长网址、超出数量的条目被静默截断或丢弃 | 保存的内容与用户输入不一致；词头截断还可能查询另一个词 | 明确校验长度、控制字符与条数；整组模板原子拒绝；词头按 Unicode 字符计数，超长不生成链接 |
| 自定义模板没有语言范围，后三条通常挤不进词卡 | 特定语言站点出现在不相关语言里；用户难以访问完整配置 | 增加可选语言范围和完整导航目录，旧格式仍适用于全部语言 |
| 导航预填在校验前写入单行输入框，未知语言也会回落英文 | URL 中的换行被浏览器删掉后可能查成另一个词；未知语言得到错误的英文站点 | 对 URL 原始词头先解码和验证，错误状态需明确改正；显式未知语言报错，只有未指定语言时采用界面默认值；worker 编码前也拒绝非法 Unicode |
| 浏览器测试新标签页加载时关闭 context，媒体设置 Promise 未处理拒绝 | 清理阶段可能报 Target closed，掩盖实际用例结果 | 清理标志、页面关闭检查和显式错误收集；导航全部入口回归通过 |

## 导向开发结果

导航页接受明确的词头语言，保留大小写、重音和字形。比如 `Gift` 选择德语时走德语词典目录，不靠拉丁字母猜成英语；日语纯汉字也通过显式语言选择与中文区分。词卡、工具栏和设置页均可进入。

新增语言只提供原站外链。既有中英文词卡仍使用原来的 adapter 和 `DictionaryEntry`，没有为尚未接入的语言伪造释义或“无法找到”结果。导航不保存独立查询历史，当前查询用扩展页 URL 片段传递，隐私文档已同步说明。

官方模板抽查样本：[日语维基词典「学校」](https://ja.wiktionary.org/wiki/%E5%AD%A6%E6%A0%A1)、[韩语维基词典「안녕」](https://ko.wiktionary.org/wiki/%EC%95%88%EB%85%95)、[Larousse maison](https://www.larousse.fr/dictionnaires/francais/maison)、[Duden Haus 搜索](https://www.duden.de/suchen/dudenonline/Haus)、[RAE casa](https://dle.rae.es/casa)。法、德、西语还提供本语言维基词典。没有把未能核实的 Jisho、Naver 或 KRDICT 搜索页写成已验证入口。

## 后续限制

- 其他语言的网页划词正文需要明确目标语言、对应 adapter、词源许可和真实在线验收；导航目录不等于已经完成这一步。
- 第三方词库的覆盖和在线状态、Oxford/Cambridge 授权、iframe/PDF/编辑器等既有边界仍在。
- 当前版本本机验证与远程基线证据分别见 [VALIDATION.md](VALIDATION.md)。0.5.0 提交 `8c03278` 与 0.6.0 提交 `843c972` 均已推送：0.5.0 的 [run 41442622503](https://github.com/lightporta/LexiLoom/actions/runs/41442622503) 仅在 macOS 浏览器流程失败，后续 0.6.0 的 [run 41450539647](https://github.com/lightporta/LexiLoom/actions/runs/41450539647) 三平台与跨平台 ZIP 比较全部成功。
